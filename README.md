# Arduino-Based Radar System
A 180-degree rotating radar that detects objects from 2cm to 400cm.

## Components Used
- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- Servo Motor SG90

## How it works
Ultrasonic sensor rotates 180 degrees with servo and measures distance. Data is visualized on Processing IDE.

## Result
Achieved 95% accuracy in object detection.
